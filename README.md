# Shanmukha Pavan Kumar — Portfolio

Responsive static portfolio built with HTML, CSS, and JavaScript.

## Project screenshots

No screenshots of the four applications were present in the project folder. The project cards therefore use the clearly marked neutral placeholder at `assets/images/project-screenshot-placeholder.svg`. Replace each card's image source in `index.html` with an actual project screenshot when available:

- Crowd Density Analysis
- Phishing Detection
- Carbon Footprint Assistant
- Photography Website

Use real captures from the corresponding application. All image areas share a 16:9 aspect ratio. If an image fails to load, the card displays a fallback message.

## Local preview

Open `index.html` in a browser, or run a local static server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Contact form

The form opens a prefilled message in the visitor's email application using the email address in the portfolio. It does not send or store messages through a website backend.
